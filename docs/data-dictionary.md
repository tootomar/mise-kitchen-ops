# Data dictionary

All files are generated by `python run_pipeline.py`. Data is synthetic.

## data/ (inputs)

**orders.csv.gz**, one row per order (about 1.4 lakh rows, 14 Aug to 8 Oct 2026)

| Column | Meaning |
| --- | --- |
| order_id | Unique order number |
| date | Service date (late-night orders after midnight keep the date the slot started) |
| kitchen | One of 10 Bengaluru kitchens |
| slot | Breakfast, Lunch, Snacks, Dinner, Late night |
| brand | EatFit, Olio Pizza, Sharief Bhai, CakeZone, Frozen Bottle, Millet Express |
| placed_at | Date and time the order was placed |
| channel | Swiggy, Zomato, Own app, Takeaway |
| items | Number of items in the order |
| order_value_inr | Order value in rupees |
| stations_on_shift | Cooks (line stations) working the slot |
| orders_in_progress | Orders already on the line when this order arrived |
| recent_avg_prep_min | Average prep time of the last 5 finished orders |
| prep_minutes | Minutes from order placed to food packed (empty if cancelled) |
| cancelled | 1 if cancelled after acceptance (for example, item out of stock) |

**complaints.csv.gz**, one row per complaint

| Column | Meaning |
| --- | --- |
| complaint_id, order_id | Complaint and the order it is about |
| date, kitchen, slot, brand | Copied from the order |
| source | Swiggy, Zomato, Call centre |
| text | What the customer wrote (English or Hinglish) |
| true_defect | Reviewer label, used only to score the taggers |

**stockouts.csv**: date, kitchen, slot, brand, item, minutes_switched_off, reason

**calendar.csv**: date, dow (0 = Monday), weekday, holiday, rain (1 = rain day), day_index

**roster_tomorrow.csv**: date, kitchen, slot, stations_planned

## outputs/ (results)

| File | Contents |
| --- | --- |
| forecast_backtest.csv | Held-out week: actual, model forecast and "same day last week", per kitchen × brand × slot × day |
| forecast_tomorrow.csv | Forecast orders for tomorrow per kitchen × brand × slot |
| prep_plan_tomorrow.csv | Prep item quantities per kitchen × slot × brand |
| prep_time_by_slot.csv | Held-out week: predicted p50 and p90, actual prep time, late share, cooks, peak queue |
| staffing_whatif_tomorrow.csv | Predicted prep time and share at risk with rostered cooks, +1 and +2 |
| complaints_tagged.csv | Every complaint with its tag and linked order details |
| hotspots.json | Hotspots with evidence, owner and first action |
| dashboard_data.json | Everything the dashboard shows, in one file |
